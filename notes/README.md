Place the PDF research notes you want to share in this directory.
Add each entry to notes.html using an ordinary relative link, for example:

<article class="paper">
  <h3><a href="notes/my-note.pdf">Title of the note</a></h3>
  <p class="detail">A short description.</p>
  <p class="paper-links"><a href="notes/my-note.pdf">PDF</a></p>
</article>

Remove the empty-note paragraph once you add the first note. No build is needed.
